# Snake Game
A **simple DSA project** implemented in **C using ncurses**.

## Concept
- **Data Structure**: Singly Linked List
- Each node represents one snake segment
- Dynamic growth without arrays

## Features
- Snake movement
- Apple eating & growth
- Score tracking
- Wall & self collision

## Build & Run
first, install [ncurses](https://invisible-island.net/ncurses/). Then run...
```sh
gcc main.c -o snake -lncurses
./snake
````
